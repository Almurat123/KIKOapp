# Copilot Instructions for KiKo Project

## CRITICAL RULES - STRICTLY FOLLOW

### 1. NO Markdown Files
**NEVER create .md files** under any circumstances for:
- Summarizing changes
- Architecture guides
- Deployment checklists
- Testing documentation
- Completion reports
- Quick references
- Any other documentation purposes

### 2. Code Only
Focus exclusively on modifying source code files:
- `.ts` (TypeScript)
- `.js` (JavaScript)
- `.jsx` (React)
- `.tsx` (React TypeScript)
- `.py` (Python)
- `.sol` (Solidity)
- Other source code formats

### 3. Talk Directly to User
- Tell the user what you did
- NO written summaries or completion reports
- Just communicate verbally/textually in the chat
- Keep it conversational

### 4. Exception
**Only create documentation if:**
- User explicitly asks "create a guide"
- User says "write documentation"
- User requests "document this"
- User says "make a README for..."

Then and ONLY then, create .md files.
