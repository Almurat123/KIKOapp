# Weekly Intent Replay Checklist

## Sample Selection
- lowest 20% confidence
- any conflict flagged
- any user cancel after intent
- any executed trade without confirmation

## Review Steps
1. Read input + decision + model output
2. Label correct intent
3. Mark root cause: rule/slot/score/classifier/LLM
4. Update rule keywords or slot requirements
5. Add new slang terms if needed

## Output
- list of updated rules
- list of new test cases
- change log for weights
