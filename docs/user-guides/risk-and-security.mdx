## 功能说明

KIKO 提供多层安全保护机制，帮助你在交易前识别潜在风险。系统会自动扫描代币合约，评估安全性，并在高风险情况下阻止交易。

## 使用场景

**必须使用风险扫描的场景：**
- 购买不熟悉的代币
- 购买新发布的代币
- 购买流动性较低的代币
- 购买社交媒体推荐的代币

**建议使用风险扫描的场景：**
- 任何交易前（作为双重检查）
- 查看代币详细信息时

## 风险等级说明

### Safe（安全）等级

**评分范围**：0-30 分

**特征**：
- 没有蜜罐风险
- 税率正常（买入/卖出税率 ≤ 5%）
- 所有权已弃权（开发者无法修改合约）
- 流动性充足
- 未发现可疑交易行为

**建议**：可以正常交易，但仍需注意市场风险。

### Medium（中等风险）等级

**评分范围**：30-70 分

**常见风险项**：
- 中等税率（5%-10%）
- 所有权未弃权（开发者可以修改合约）
- 流动性一般
- 可能存在其他潜在风险

**建议**：
- 谨慎交易
- 只投入你能承受损失的资金
- 关注代币的后续发展
- 不要投入过多资金

### High Risk（高风险）等级

**评分范围**：70-100 分

**常见风险项**：
- 蜜罐检测（可能无法卖出）
- 高税率（卖出税率 > 10%）
- 所有权未弃权且有可疑行为
- 流动性极低
- 黑名单风险
- 其他严重风险

**建议**：
- **强烈建议避免交易**
- 如果坚持交易，只投入极小金额作为试验
- 做好本金完全损失的准备

## 危险代币与交易阻止

### 自动阻止机制

KIKO 会在以下情况自动阻止交易：

**1. 蜜罐检测**
- **风险**：你买入后可能无法卖出
- **系统行为**：自动阻止交易
- **提示**："该代币为蜜罐，无法卖出"

**2. 价格影响过大**
- **阈值**：根据执行模式动态设置（快速执行模式默认约 5%）
- **系统行为**：自动阻止交易
- **提示**："价格影响过大，交易可能造成严重损失"
- **注意**：不同执行模式可能有不同的价格影响限制

**3. 严重风险项**
- **包括**：高税率、黑名单、可暂停交易等
- **系统行为**：显示强烈警告，可能需要额外确认
- **提示**："该代币存在严重风险"

即使交易未被自动阻止，你也应该手动检查风险：

  <Step title="检查关键风险项">

  </Step>
</Steps>

## 风险检测项详解

### 蜜罐检测（Honeypot）

**什么是蜜罐？**
蜜罐是一种陷阱代币，你只能买入但无法卖出。这是常见的骗局。

**检测方法**：
系统通过第三方安全服务（GoPlus）分析代币合约，检测是否存在蜜罐风险。

**如何处理**：
- **如果是蜜罐**：绝对不要交易，避免资金损失
- **系统行为**：自动阻止蜜罐代币的交易

### 交易税率（Buy/Sell Tax）

**什么是交易税？**
某些代币会在买入或卖出时收取一定比例的费用。这是代币合约的设计。

**税率等级**：
- **正常税率**：≤ 5%（可接受）
- **中等税率**：5%-10%（需注意）
- **高税率**：10%-20%（风险较高）
- **极高税率**：> 20%（强烈建议避免）

**如何查看税率**：
在风险报告中会显示买入税率和卖出税率。

**注意事项**：
- 卖出税率比买入税率更重要
- 高税率会显著影响你的盈利
- 税率可能在合约未弃权时被修改

### 所有权状态（Ownership）

**什么是所有权弃权？**
当开发者"弃权"合约所有权后，就无法再修改合约参数（如税率、交易状态等）。

**状态说明**：
- **已弃权**：✓ 安全，开发者无法修改
- **未弃权**：⚠️ 风险，开发者可以随时修改参数
- **可恢复所有权**：⚠️ 高风险，开发者可能恢复并修改

**如何处理**：
- 优先选择已弃权的代币
- 未弃权的代币需要谨慎评估开发者信誉
- 可恢复所有权的代币风险极高

### 流动性（Liquidity）

**什么是流动性？**
流动性是指代币在市场上的可交易深度。流动性低意味着少量交易就可能造成价格大幅波动。

**流动性等级**：
- **充足**：> $100,000（可正常交易）
- **一般**：$10,000 - $100,000（需注意）
- **较低**：< $10,000（风险较高）
- **极低**：< $1,000（不建议交易）

**影响**：
- 流动性越低，价格影响越大
- 大额交易可能无法全部成交
- 卖出时可能无法立即找到买家

### 其他风险项

**黑名单**：
代币合约可能包含黑名单机制，某些地址可能被禁止交易。

**可暂停交易**：
合约所有者可能暂停交易，导致你无法买卖。

**可增发代币**：
合约可能允许无限增发代币，导致价格下跌。

**自毁功能**：
合约可能包含自毁功能，可能被恶意触发。

</Warning>

</Warning>

### 你需要承担的责任

**1. 自己的研究（DYOR）**
- 不要仅依赖系统的风险扫描
- 深入了解项目背景和团队
- 查看代币合约代码（如果可能）
- 关注社区讨论和媒体报道

**2. 风险管理**
- 只投入你能承受损失的资金
- 不要投入超过你总资产的合理比例
- 设置止损和止盈策略
- 分散投资，不要把所有资金投入单一代币

**3. 安全意识**
- 保护好你的钱包和私钥
- 不要在不安全的网络环境下使用
- 谨慎对待社交媒体推荐
- 警惕钓鱼和诈骗

**4. 合规责任**
- 确保你的交易符合当地法律法规
- 了解税务义务
- 不要参与非法活动

</Warning>

## 合约验证状态

### 什么是合约验证？
合约验证是指开发者将智能合约的源代码提交到区块链浏览器（如 Etherscan），供公众查看。只有验证过的合约才能进行深度代码扫描。

### 未验证合约的风险
- 无法进行本地代码扫描（无法查看源代码）
- 只能依赖第三方 API（如 GoPlus）的基础风险检测
- 风险信息可能不完整

### 如何处理未验证合约？
如果系统提示"合约未验证，无法扫描"，建议：
1. 查看第三方 API 返回的基础风险信息（如税率、流动性等）
2. 谨慎评估项目背景和团队
3. 只投入你能承受损失的资金
4. 优先选择已验证的合约进行交易
