### 🐦 Farcaster：追踪 Web3 核心讨论

你可以通过自然语言查询 Farcaster 上的热门话题和讨论内容。

#### 常用指令
- `"Farcaster 上现在的热门话题是什么？"`
- `"搜搜大家对最近 Base 链新币的评价"`
- `"总结一下某地址在社交平台上的活跃度"`

<Info>
  **为什么关注 Farcaster？** 它是目前 Web3 原生用户密度最高、机器人干扰最少的社交协议。
</Info>
