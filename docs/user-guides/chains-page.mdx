The Chains page provides data on on-chain activity and capital accumulation across major Web3 public chains (Layer 1 & Layer 2). The core data on this page is powered by open-source queries from [Dune Analytics](https://dune.com).

---

## Core On-Chain Metrics

At the top of the page, you can see aggregated data for all tracked public chains:

- **Total TVL (Total Value Locked)**: The total capital size across all tracked public chains.
- **24h Transactions**: The sum of all transactions processed across all public chains in the last 24 hours.
- **Active Wallets**: The total number of unique wallet addresses participating in interactions across the network.
- **Avg TVL Change**: The weighted average percentage of 24h capital inflow/outflow based on individual chain TVL.

---

## Public Chain Rankings

The main body of the page is a list of public chains ranked by **TVL (Total Value Locked)** in descending order. This leaderboard clearly shows where capital is accumulating.

For each chain, we display the following key data:

### 1. TVL and 24h Change
TVL is the most critical metric for measuring the ecosystem prosperity of a public chain. The 24-hour TVL change rate (green for inflow, red for outflow) helps you quickly capture recent "hot chains." For example, a sudden surge in TVL for a specific Layer 2 often indicates high-yield DeFi protocols or trending meme coins on that chain.

### 2. 24h Transactions
Reflects the actual usage frequency of the chain. Some chains may have low TVL but extremely high transaction counts (e.g., Solana, Base), which typically indicates active high-frequency trading (meme speculation, GameFi, etc.).

### 3. Active Wallets
Reflects the actual user base of the chain. Combined with transaction counts, you can determine whether a chain is dominated by a few "whales" or has broad retail participation.

## Data Source Note

All on-chain fund flows and activity data on this page are retrieved via the **Dune Analytics API**. Dune relies on its powerful community-driven open-source queries to provide deeper and more accurate cross-chain comparison data than traditional block explorers.
