**Login**: Supports Google, Farcaster, Email, and Twitter (X). Custodial wallets mean no seed phrase required.

**Supported Chains**: Base, Ethereum, BSC, Arbitrum, Optimism, Polygon, Solana.

**Trade Failures**: Common reasons include insufficient balance, exceeded slippage, high price impact, or high-risk token flags. Note that failed trades still consume Gas.

**No Confirmation Cards**: Swaps are executed directly with Allowance. Execution happens upon sending the command. Slippage can be configured in user settings or via commands.

**Risk Scanning**: Enter `"Is this token safe? 0x..."`. We categorize results into Safe, Medium, and High Risk. Critical traps like honeypots are blocked automatically.

**Copy Trading**: You can follow multiple wallets with sufficient balance. Execution prices may differ from the target wallet due to timing lags. Pause or delete followers directly in chat.
