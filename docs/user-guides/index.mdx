## 核心概念

<Tip>
**对话即交易**：使用自然语言描述你的需求，KIKO 会自动帮你完成交易。
</Tip>

<Info>
**安全优先**：KIKO 会在交易前自动扫描代币风险，保护你的资金安全。
</Info>

<Warning>
**风险提示**：加密货币交易存在风险，请务必做好自己的研究（DYOR）。KIKO 不提供投资建议。
</Warning>

2. **[开始使用](/user-guides/getting-started)** - 完成账户设置和钱包连接
3. **[聊天与指令](/user-guides/chat-and-commands)** - 学习如何与 KIKO 交互

5. **[风险与安全](/user-guides/risk-and-security)** - 理解安全机制

完成基础学习后，你可以探索：
