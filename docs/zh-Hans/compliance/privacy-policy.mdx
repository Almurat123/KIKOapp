# 隐私政策

**生效日期：2026年4月19日 | 版本：v2.1**

本隐私政策解释了 KIKO MiniApp（以下简称"本服务"）在您使用过程中如何收集、使用和保护数据。本服务由 KIKO 贡献者（"KIKO Contributors"）开发和维护。

---

## 1. 我们收集哪些数据

### 1.1 您提供的信息
- **第三方登录标识符 (OAuth ID)**：当您通过 Farcaster 或其他社交账户登录时，我们会接收该平台的唯一标识符以识别您的账户。
- **钱包地址**：您的链上钱包地址，用于关联交易记录和设置。
- **聊天输入内容**：您在聊天界面中输入的自然语言指令，用于 AI 解析和链上操作执行。
- **图片提示词和参考图片**：您提供的图片生成输入，包括提示词、上传的源图片、修改说明和其他相关指令。

### 1.2 自动生成的数据
- **会话信息**：会话创建时间、使用的 AI 模型、会话标题及其他元数据。
- **交易记录**：链上交易哈希、代币信息、交易金额及其他用于历史记录展示的数据。
- **使用活动数据**：消息数量、跟单交易配置状态以及用于优化服务的聚合统计数据。
- **生成图片与审核元数据**：图片资产、修订后的提示词、审核结果以及任何图片生成请求的分享目标。

### 1.3 我们**不**收集的数据
- **IP 地址**：本服务使用 Cloudflare 边缘网络在请求到达 KIKO 服务器之前拦截来自受限地区的访问。KIKO 不存储任何用户的 IP 地址。
- **私钥或助记词**：您的私钥由第三方提供商 Privy 独立管理，KIKO 无法访问或存储。
- **生物识别数据或身份文件**：本服务不需要任何 KYC（了解你的客户）信息。

除非您明确将其分享到需要持久链接或嵌入的公开场景，否则生成图片通常仅保留在您的账户历史中。

## 2. 我们如何使用数据

| 数据类型 | 目的 |
|---|---|
| OAuth ID / 钱包地址 | 账户识别、设置同步、安全验证 |
| 聊天输入内容 | AI 指令解析、链上操作执行、上下文理解 |
| 图片提示词 / 参考图片 | 图片生成、图片编辑、审核与安全过滤 |
| 会话元数据 | 历史记录展示、服务连续性 |
| 交易记录 | 交易历史查询、跟单交易分析 |
| 使用活动数据 | 服务质量监控、配额管理 |
| 生成图片 | 历史展示、私密存储、用户主动分享和输出复核 |

本服务**不会**将您的数据用于广告、出售给第三方或任何与提供本服务无关的目的。

## 3. 数据保留期限

本服务实施自动数据清理：

| 数据类型 | 保留期限 |
|---|---|
| 聊天消息内容 | **30天**，随后自动删除 |
| 消息流式传输片段 | **3天**，随后自动删除 |
| 会话元数据（标题、时间戳等） | 在消息清理后 **90天** 内删除 |
| 追踪钱包的交易记录 | **90天**，随后自动删除 |
| 账户基本信息（OAuth ID、钱包地址） | 贯穿账户生命周期 |
| 跟单交易配置 | 保留至您手动删除 |

出于法律要求或安全调查的需要，数据保留期限可能会延长。
