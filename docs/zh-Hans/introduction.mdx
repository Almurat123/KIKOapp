## KiKo 是什么？

**KiKo** 是一个将大语言模型深度融入 Web3 交易场景的 Labs 实验室。

我们相信每个 AI 模型都有其独特的优势。KiKo 整合了 **DeepSeek**、**Grok**（xAI）等主流大模型，针对每个模型的特点进行调度，让它们在信息获取、风险分析、Market 研判等不同场景中各司其职——帮助交易者以最快的速度，获取到所有可能影响市场走向的关键信息。

## 我们在解决什么问题？

传统的加密货币交易界面复杂臃肿：你需要在多个平台之间切换、手动查询数据、理解晦涩的链上指标，才能做出一个决策。

KiKo 的答案是：**用自然语言替代界面操作**。

你不需要学习复杂的交易界面，只需要用日常语言描述你的需求——AI 会调度合适的工具，完成从信息收集到链上执行的完整流程。

## Agent 模式

KiKo 支持 **Agent 驱动模式**：AI 不只是回答你的问题，而是作为你的专属 Agent 主动执行任务。

- 模型与模型之间协同工作，自动拆解复杂指令
- 自然语言即指令，无需手动配置参数
- Agent 替你监控市场、执行策略、发出提醒

这让大模型真正成为你的交易伙伴，而不只是一个聊天窗口。

## 核心能力

  <Accordion title="信息分析平台">
    实时聚合多维度市场信号，覆盖所有可能影响行情走向的信息层：

    - **市场行情**：价格、成交量、流动性、涨跌幅实时追踪

    KiKo 配套了自己的交易执行引擎，实时同步所支持链上的最新交易路径：

    - **智能 Swap**：自然语言发起，自动寻优路由，多链支持（Base、Ethereum、Solana）
    - **Copy Trading**：自动复制指定钱包的链上交易行为
    - **风险扫描**：交易前自动检测合约安全，识别貔貅、蜜罐等常见陷阱
    - **钱包分析**：盈亏追踪、历史行为分析、持仓透视
  </Accordion>

  <Accordion title="多模型调度">
    KiKo 不绑定单一模型，而是根据任务类型智能选择最合适的大模型：

    - **DeepSeek**：深度推理、复杂分析场景
    - **Grok**（xAI）：实时 X 平台数据、网络搜索、多模态理解
    - **GPT 系列**：通用任务与工具调用

    每个模型的优势在对应场景中充分发挥，而不是用同一个模型应对所有问题。
  </Accordion>

## 常见问题

<AccordionGroup>
  <Accordion title="为什么用 AI 来交易？">
    交易的本质是信息差。KiKo 让你在做决策之前，同时完成安全扫描、跨链比价、链上分析，把原本需要在多个平台耗费大量时间的工作，压缩到一次对话中完成。
  </Accordion>
  <Accordion title="我的私钥安全吗？">
    KiKo 使用 **Privy** 进行密钥托管。你的私钥由 Privy 加密存储（HSM 级别），KiKo 本身无法访问。每笔交易均需你的明确确认，KiKo 不会在未经授权的情况下发起任何签名。
  </Accordion>
  <Accordion title="支持哪些区块链？">
    目前主要支持 **Base**、**Ethereum** 和 **Solana**。你可以在对话中指定链，系统会自动识别并切换网络。我们将持续扩展所支持的链。
  </Accordion>
</AccordionGroup>
