## 创建跟单

输入指令，例如：
- `"复制钱包 0x...，每次买入 100 USDC"`
- `"跟随 0x...，买入 50 USDC，止盈 50%，止损 20%"`

系统会显示配置卡片，确认后开始运行。

## 参数

**必填**：目标钱包地址、每次买入金额（USD）。

**可选**：链（不指定则按地址格式推断，0x→Base，Base58→Solana）、止盈/止损比例、最小交易金额、最大滑点、镜像卖出（目标卖出时是否跟卖，默认开启）。

## 安全设置

- **重复买入冷却**：同一代币的最小买入间隔（分钟）
- **最小市值 / 流动性 / 目标买入价值**：过滤低质量交易

## 流程

监听目标钱包 → 检测买入/卖出 → 满足条件则执行跟单 → 止盈/止损触发时自动卖出。跟单买入时会进行风险检查，高风险代币可能被阻止。

## 管理

- 查看：`"查看我的跟单列表"`
- 暂停：`"暂停跟单 0x..."`
- 恢复：`"恢复跟单 0x..."`
- 删除：`"删除跟单 0x..."`
- 修改：`"修改跟单 0x...，买入金额改为 150 USDC"`

同一目标钱包（同链）只能有一个跟单配置。每次跟单需支付 Gas，注意资金与时间差风险。选择目标钱包前建议查看其交易记录与盈亏。
