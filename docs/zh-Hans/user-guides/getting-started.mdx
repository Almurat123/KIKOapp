## 登录

支持：**Google**、**Farcaster**、**Email**、**Twitter**。使用 Privy，登录后自动创建托管钱包，私钥由 Privy HSM 加密存储。

## 支持的链

Base、Ethereum、BSC、Arbitrum、Optimism、Polygon、Solana。可在对话中指定链，如「在 Base 链上买」。

## 基础操作

**查询**：`"钱包余额"`、`"ETH 价格"`、`"Base 链前 5 热门币"`

**Swap**：`"用 20 USDC 买 ETH"` —— 直接执行，无确认卡片。详见 [Swap 交易](/zh-Hans/user-guides/swap-trading)。

**风险扫描**：`"这个币安全吗？0x..."`

**跟单**：`"复制钱包 0x...，每次买入 100 USDC"` —— 详见 [Copy Trading](/zh-Hans/user-guides/copy-trading)。

建议在交易前先配置 [用户设置](/zh-Hans/user-guides/user-settings)。
