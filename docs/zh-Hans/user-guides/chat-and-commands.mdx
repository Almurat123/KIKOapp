## 输入

自然语言输入即可，无需特殊格式。例如：`"钱包余额"`、`"用 100 USDC 买 ETH"`、`"这个币安全吗？0x..."`。

## 建议系统

根据**输入前缀**显示建议，辅助快速完成指令。点击输入框或开始输入时会出现，点击建议项即可填入。示例：输入 `Swap` 会显示 `Swap 0.1 ETH to [粘贴地址]`；输入地址会显示 `Swap`、`Copy Trade`、`Check` 等操作。

## 交易执行

Swap 均为 Allowance 直接执行，**无确认卡片**。详见 [Swap 交易](/zh-Hans/user-guides/swap-trading)。
