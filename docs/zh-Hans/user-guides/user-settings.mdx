KiKo 的设置分布在两处：

- **交易偏好**（聊天界面右上角设置按钮）— 影响每一笔 Swap 的执行行为
- **账户设置**（设置页面）— 影响授权、安全与账户管理

你也可以直接在对话框告诉 AI「帮我修改设置」，AI 会引导你完成配置。

---

## 交易偏好

点击聊天界面右上角的 **Custom Reply（⚙️）** 图标打开。设置自动保存，无需手动确认。

### 快速交易模式（Fast Swap Mode）

| | |
|---|---|
| **默认值** | 关闭 |
| **影响** | 开启后跳过手动确认步骤，直接执行交易 |

> 开启后「交易前显示报价」选项自动禁用。适合熟悉链上操作、追求速度的用户；新手建议保持关闭。

---

### 默认 Swap 金额

| | |
|---|---|
| **默认值** | `0.1` |
| **单位选项** | Native Token（原生代币）/ USDC / USDT |
| **默认单位** | Native Token |
| **影响** | 当你的指令没有指定金额时（如「买 ETH」），系统使用此默认金额 |

---

### 交易前扫描代币安全（Check token security before swap）

| | |
|---|---|
| **默认值** | 开启 |
| **影响** | 每次 Swap 前，AI 自动对目标代币进行风险扫描，识别貔貅、蜜罐、黑名单等风险 |

> 关闭后交易速度更快，但失去主动风险防护。建议保持开启。

---

### 交易前显示报价（Show quote before swap）

| | |
|---|---|
| **默认值** | 开启 |
| **影响** | 执行前展示预计到账金额，等待你确认后再发送交易 |

> 开启「快速交易模式」后此项自动禁用。

---

### 滑点容忍度（Slippage Tolerance）

| 模式 | 说明 | 默认值 |
|------|------|--------|
| **Auto（自动）** | 使用 KiKo 当前的系统默认滑点值。在当前版本中，界面默认值为 10%。 | ✅ 默认 |
| **Custom（自定义）** | 手动输入百分比，范围 0.1% – 50%；买入卖出使用相同值 | 默认值 10% |

> 滑点过低可能导致交易失败；过高则可能造成资金损失。Auto 模式会直接使用系统默认值，无需手动管理百分比。

---

### MEV 保护（MEV Protection）

| | |
|---|---|
| **默认值** | 开启 |
| **当前实现** | Flashbots Protect 私有交易（仅 Ethereum 主网） |

MEV 保护的执行策略：

| 场景 | 策略 |
|---|---|
| **自然语言交易（Fast Swap）** | ✅ 启用 MEV 保护 |
| **Copy Trading - turbo** | ❌ 关闭（优先极低延迟） |
| **Copy Trading - normal / safe** | ✅ 启用 MEV 保护 |

> 当前只有 Ethereum 主网会走 Flashbots 私有内存池。非 Ethereum 链不会启用该保护路径。

---

### 价格偏差检查（Price Deviation Check）

| | |
|---|---|
| **默认值** | 开启 |
| **触发场景** | 每次通过自然语言发起的 AI Swap（不含 Copy Trading，Copy Trading 有独立流程） |
| **影响** | 当模拟报价价格与 DEX Screener / GeckoTerminal 参考价偏差超过 50% 时，AI 自动阻止并提示用户 |

> 有效防止因价格操纵、流动性极度稀薄或合约异常导致的严重资金损失。

## 账户设置

点击右上角头像或导航栏进入「设置页面」。

### 授权自动交易（Session Signer）

KiKo 支持通过授权 **Session Signer** 让 AI Agent 自动执行交易。KiKo 没有手动签名的流程，所有交易均通过自动签名执行——Session Signer 授权决定了 AI 是否可以在链上代你发起签名。

| 网络 | 说明 |
|------|------|
| **Ethereum（EVM）** | 授权 EVM 链上的自动交易签名 |
| **Solana** | 授权 Solana 链上的自动交易签名 |

> 授权后 AI 可在你设定的条件下自动执行 Swap、跟单等操作。你可随时在设置页面撤销授权。

---

### Polymarket 交易授权

| | |
|---|---|
| **默认值** | 未授权 |
| **影响** | 开启后可通过 KiKo 直接参与 Polymarket 预测市场的链上交易 |

---

### Agent 模式（Agent Mode）

| | |
|---|---|
| **默认值** | 关闭 |
| **影响** | 开启后暴露机器可读的界面锚点与坐标映射，供外部自动化 Agent 操控界面使用 |

> 这是面向开发者和自动化集成的高级功能，普通用户无需开启。

---

### 导出钱包私钥（Backup Recovery Phrase）

在设置页面的 **Security & Privacy** 区块可导出私钥：

- **EVM 钱包**（Ethereum / Base 等）
- **Solana 钱包**

导出由 [Privy](https://privy.io) 安全处理。KiKo 本身无法访问你的私钥。

详见 [风险与安全](/zh-Hans/user-guides/risk-and-security)。
