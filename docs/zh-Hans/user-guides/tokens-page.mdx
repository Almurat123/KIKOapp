## 热门代币排序算法

Tokens 页面的默认排序并非简单的按交易量或涨幅排列，而是采用了 KiKo 独家研发的**多因子动量算法（Multi-factor Trending Score）**。

该算法综合考量了以下维度：
- **短期爆发力**：5 分钟（5m）与 1 小时（1h）的价格变化权重极高，能迅速捕捉刚启动的新币。
- **中期持续性**：6 小时（6h）与 24 小时（24h）的价格变化。
- **交易活跃度**：24 小时交易量（Volume）与交易笔数（Txns）。
- **流动性健康度**：池子流动性（Liquidity）与独立交易者估算（Makers）。

> **为什么这么做？**
> 传统的 24 小时涨幅榜往往被已经被拉高（甚至即将砸盘）的老币占据。KiKo 的算法对 5m 和 1h 的异动极其敏感，让你能第一时间看到刚刚打响第一枪的早期项目。

## Launchpad 深度集成

对于通过各大 Launchpad（发射平台）公平发射的代币，KiKo 提供了专属的展示与解析功能。

### 1. 平台标识与直达链接
在代币列表中，你会看到精美的 Launchpad 专属 Icon（如 Pump.fun, Clanker, Four.meme 等）。点击该图标，即可直接跳转到该代币在对应 Launchpad 的官方详情页，方便你验证合约或参与早期曲线交易。

### 2. 社交上下文 (Social Context)
KiKo 会自动抓取并展示 Launchpad 提供的社交信息，包括：
- **创建者地址 / 标签**（Creator）
- **官方网站**
- **X (Twitter) 链接**
- **Farcaster 链接**

### 3. 早期涨幅估算 (Launch Multiple)
为了让你直观感受代币的早期爆发力，KiKo 会根据各 Launchpad 的历史初始开盘价，估算当前价格相对于开盘价的倍数（如 `x15`、`x120`）。

**当前各平台的估算基准价（USD）：**
- **Base - Clanker**: `$0.00000025`
- **Base - Zora**: `$0.00001`
- **Base - Virtuals**: `$0.0001`
- **Solana - Pump.fun**: `$0.00003`
- **BSC - Four.meme**: `$0.000035`

*(注：此倍数仅供参考，实际开盘价可能因网络拥堵或初始池设置略有浮动。)*

## Token Details (代币详情页)

点击任意代币，即可进入 Token Details 页面。这里汇集了该代币的所有关键信息。

在详情页中，你可以看到：
- **实时价格与多时间维度涨跌幅**（5m, 1h, 6h, 24h）
- **核心数据**：市值（Market Cap）、完全稀释估值（FDV）、流动性（Liquidity）、24h 交易量
- **交易统计**：24h 买入/卖出笔数、持币人数估算
- **安全与社交信息**：合约地址、创建时间、社交媒体链接

### 收藏与自定义设置

在详情页的右上角，你可以点击**「收藏」**（Star）按钮。
收藏代币后，KiKo 会在后续的更新中为你提供针对该代币的自定义价格提醒、异动推送以及更深度的追踪服务。
