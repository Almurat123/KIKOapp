# 深度代币分析

KiKo 的 AI 不只能交易，它更是你的专业 Web3 分析师。

## 核心分析工具

### 1. 安全扫描 (Risk Scan)
基于多级风控模型，KiKo 可以深入分析 token 合约。
- **检测项**: 蜜罐检测、开发者持有比例、是否可弃权、交易税设置。
- **使用**: `"这个代币安全吗？0x..."`

### 2. 交易员画像 (Wallet PnL)
分析任何钱包的历史表现。
- **数据**: 总利润、胜率、平均持筹时间、擅长领域。
- **使用**: `"分析一下这个聪明钱：0x..."`

### 3. 项目背景深挖 (Deep Website Analyzer)
AI 会启动真实浏览器访问项目官网，提取团队、白皮书和技术文档。
- **功能**: 总结项目愿景，查找潜在的技术风险。
- **使用**: `"深入分析一下这个网站：https://..."`

### 4. 早期买家发现 (Early Buyers)
寻找代币最开始被谁买入，判断是否由机构或聪明钱布局。
- **使用**: `"谁是这个代币的最早买家？"`

---

> [!NOTE]
> 所有的分析报告都可以在对话界面中以可视化的图表或列表形式展示，方便你快速做出判断。
