# 快速开始

欢迎来到 KiKo！只需几分钟，你就能完成从连接钱包到发起第一笔 AI 驱动交易的全过程。

## 1. 登录并连接钱包

KiKo 使用 **Privy** 提供流畅的登录体验。

- 点击首页的 "Login" 按钮。
- 你可以选择使用 **Email**、**Google** 账户，或直接连接已有的 **MetaMask/Phantom** 等钱包。
- 登录后，KiKo 会自动为你准备好适用的链环境。

## 2. 发起对话

KiKo 的核心在于对话框。试着输入以下指令：

- `"帮我看看现在的热门代币有哪些？"`
- `"分析一下这个地址的盈亏情况：0x..."`
- `"我想在 Base 链买 $50 美金的 ETH"`

## 3. 进行第一笔交易

当你想交易时，KiKo 会为你准备好交易卡片：

1. **输入意图**: 例如“Buy 0.1 ETH on Base”。
2. **确认预览**: 界面会弹出一个包含实时报价、Gas 预估和滑动点差的交易卡。
3. **点击确认**: 在你的钱包插件中点击签名，交易即刻上链。

## 4. 探索更多

你可以通过左侧导航栏访问以下页面进行更深入的操作：

- **Wallet**: 查看你的资产分布和历史足迹。
- **Risk**: 进行深度的代币安全性扫描。
- **Social**: 看看 Farcaster 上的热点话题。

---

> [!TIP]
> 如果你发现 AI 没有识别你的意图，可以尝试更清晰的描述，例如加上具体的链名（如 "on Solana"）。
