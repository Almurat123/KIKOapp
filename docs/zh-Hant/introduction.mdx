## 什麼是 KiKo？

**KiKo** 是一個將 **大型語言模型 (DeepSeek 與 xAI Grok)** 與 **鏈上執行引擎** 深度融合的智能終端，讓複雜的 Web3 操作回歸自然語言。

KiKo 內建了豐富的自訂工具，涵蓋交易的方方面面。透過 AI 智能調度，這些工具協同工作，幫你完成從資訊收集到交易執行的全流程。

<AccordionGroup>
  <Accordion title="核心功能">

### 交易執行

智能交易執行、自動路由優化、多鏈支援，讓你輕鬆完成各種鏈上操作。只需用自然語言描述需求，系統會自動找到最優路徑並執行交易。

[了解更多 →](/zh-Hant/user-guides/swap-trading)

### 風險掃描

全方位的安全掃描機制，自動識別潛在風險，保護你的資金安全。在交易前自動檢查合約風險，為你提供詳細的評估報告。

[了解更多 →](/zh-Hant/user-guides/risk-and-security)

### 市場數據

即時市場數據、歷史趨勢分析、熱門資產追蹤，幫助你把握市場脈搏。獲取最新價格、交易量、流動性等關鍵指標。

### 社交情報

整合主流社交平台趨勢追蹤、熱門話題發現、私訊通知提醒，讓你第一時間捕捉市場信號。支援 Farcaster 和 X（Twitter）等平台的深度搜尋，不錯過任何有價值的討論。

### 預測市場

獲取預測市場的集體智慧，了解市場對未來事件的預期。透過賠率分析洞察市場情緒和未來趨勢。

### 錢包分析

深度鏈上分析、盈虧追蹤、行為監控，讓你全面了解資產狀況。追蹤錢包歷史交易，分析盈虧表現，發現隱藏的市場信號。

### 自動化工具

智能跟單、價格警報、行為監控等自動化策略，讓交易更高效。設定自動化規則，讓系統幫你執行重複性操作。

[了解更多 →](/zh-Hant/user-guides/copy-trading)

### 研究工具

全面的 Web 搜尋能力，可以查詢網上的幾乎任何資訊，幫助你獲取最全面的市場資訊和研究資料。整合多源資訊，為你的決策提供參考。

## 常見問題 (FAQ)

<AccordionGroup>
  <Accordion title="為什麼我需要用 AI 來交易？">
    KiKo 能在交易前為你完成 [安全掃描] + [跨鏈比價] + [社交背書] + [鏈上分析] 的綜合判斷，幫你做出更明智的決策。在資訊爆炸的時代，AI 幫助你快速處理海量數據，抓住交易機會。
  </Accordion>
  <Accordion title="我的私鑰安全嗎？">
    KiKo 使用 **Privy** 進行私鑰管理。你的私鑰由 Privy 控制和管理，與 KiKo 無關。Privy 使用硬體安全模組（HSM）加密儲存私鑰，確保安全。KiKo 只根據你的顯式指令調用簽名權限，每一筆交易都需要你的確認。
  </Accordion>
  <Accordion title="KiKo 支援哪些區塊鏈？">
    KiKo 主要支援 Base、Ethereum 和 Solana 等主流區塊鏈網路。你可以透過聊天直接指定想要使用的鏈，系統會自動識別並切換到對應的網路。
  </Accordion>
</AccordionGroup>
