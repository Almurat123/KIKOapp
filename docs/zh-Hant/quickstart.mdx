title: '極速入駐'
description: '從 0 到 1 開啟你的 AI 錢包之旅'
---

歡迎使用 KiKo！本指南只包含「當前已實現且用戶可直接操作」的快速入駐流程。

<Steps>
  <Step title="1) 登入（建立你的 KiKo 錢包）">
    KiKo 使用 **Privy** 進行身份認證，目前支援：

    - **Google 登入**
    - **Farcaster 登入**
    - **Passkey 登入**（Face ID / Touch ID / Windows Hello 等）

    登入成功後，系統會自動為你建立一個 **託管錢包（Embedded Wallet）**，無需記憶助記詞。
  </Step>

  <Step title="2) 準備資金（先從 Base 開始）">
    為了完成第一筆交易，你需要把資金轉入你的 KiKo 錢包（或確保錢包裡已有資金）。

    - **Base（推薦）**：Gas 低，適合新手
    - **Ethereum**：Gas 可能較高
    - **Solana**：進行任何交易都需要 **SOL** 支付手續費（建議至少保留 **0.005 SOL**）

    <Tip>
      不確定怎麼做？可以直接問：`「我現在在哪條鏈有餘額？把收款地址給我。」`
    </Tip>
  </Step>

  <Step title="3) 先做一次查詢（驗證你已就緒）">
    在對話介面嘗試：

    - `「幫我看看錢包餘額」`
    - `「ETH 現在多少錢？」`
    - `「Base 鏈上成交額前 5 的幣是哪些？」`
  </Step>

  <Step title="4) 做第一筆小額 Swap（建議先小額）">
    直接輸入交易意圖，例如：

    - `「用 20 USDC 買入 ETH」`
    - `「在 Base 鏈上，用 50 USDC 買入 DEGEN」`

    系統會展示交易卡片供你核對（價格、滑點、價格影響、風險提示等）。根據你的設定與執行模式，交易可能需要你手動執行，也可能在開啟快速交易模式時直接執行。
  </Step>

  <Step title="5) 不熟悉的代幣先做風險掃描">
    在交易前先發地址：

    - `「這個代幣安全嗎？0x...」`
    - `「在買入之前先掃描一下這個代幣風險：0x...」`
  </Step>
</Steps>

<Warning>
  KiKo 不提供投資建議。加密資產波動大，請只投入你能承受損失的資金。
</Warning>
