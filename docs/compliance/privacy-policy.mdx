# 隐私政策 / Privacy Policy

**生效日期：2026年2月20日 | 版本：v2.0**

本隐私政策说明 KIKO MiniApp（「本服务」）由其贡献者团队（「KIKO 贡献者」）在您使用过程中收集、使用和保护数据的方式。

---

## 第一条 我们收集什么数据

### 1.1 您主动提供的数据
- **第三方登录标识（OAuth ID）**：您通过 Farcaster 或其他社交账户登录时，我们接收该平台提供的唯一标识符，用于识别您的账户。
- **钱包地址**：您的链上钱包地址，用于关联您的交易记录和设置。
- **聊天输入内容**：您在对话界面输入的自然语言指令，用于 AI 解析并执行链上操作。

### 1.2 自动生成的数据
- **会话信息**：会话创建时间、使用的 AI 模型、会话标题等元数据。
- **交易记录**：通过本服务执行的链上交易哈希、代币信息、交易金额等，用于历史记录展示。
- **使用活动数据**：消息数量、跟单配置状态等聚合统计，用于服务优化。

### 1.3 我们不收集的数据
- **IP 地址**：本服务通过 Cloudflare 边缘网络对禁止地区实施访问拦截，该过程在请求到达本服务服务器之前完成，本服务不存储任何用户 IP 地址。
- **私钥或助记词**：您的私钥原文由第三方服务商 Privy 独立保管，本服务无法访问或存储。
- **生物特征或身份证件**：本服务不要求任何 KYC 信息。

## 第二条 我们如何使用数据

| 数据类型 | 用途 |
|---|---|
| OAuth ID / 钱包地址 | 账户识别、设置同步、安全验证 |
| 聊天输入内容 | AI 解析指令、执行链上操作、上下文理解 |
| 会话元数据 | 历史记录展示、服务连续性 |
| 交易记录 | 交易历史查询、跟单分析 |
| 使用活动数据 | 服务质量监控、限额管理 |

本服务**不会**将您的数据用于广告投放、出售给第三方或任何与提供本服务无关的目的。

---

## 第三条 数据保留期限

本服务实行自动数据清理机制：

| 数据类型 | 保留期限 |
|---|---|
| 聊天消息内容 | **30 天**后自动删除 |
| 流式消息分块数据 | **3 天**后自动删除 |
| 会话元数据（标题、时间等） | 消息删除后 **90 天**内清理 |
| 链上交易记录（跟踪钱包） | **90 天**后自动清理 |
| 账户基本信息（OAuth ID、钱包地址） | 账户存续期间保留 |
| 跟单配置 | 您主动删除前保留 |

法律要求或安全调查需要的情况下，保留期限可能延长。

## 第五条 数据安全

- 本服务使用行业标准加密协议传输数据（HTTPS/TLS）。
- 数据库存储于受访问控制保护的云端基础设施。
- 本服务不在日志中记录私钥、助记词或用户完整交易签名。
- 如发生影响用户数据安全的事件，KIKO 贡献者团队将通过界面公告或官方 Farcaster 频道尽快通知受影响用户。

## 第六条 您的数据权利

您对自己的数据拥有以下权利：

- **查阅权**：您可在界面中查看您的聊天历史、交易记录和跟单配置。
- **删除权**：您可在界面中删除单条会话；账户层面的数据删除请通过官方 Farcaster 频道提出请求。
- **撤销授权**：您可随时关闭自动交易功能，撤销 KIKO 通过 Privy 代签的授权。

本服务不以任何注册法律实体名义运营，数据权利请求的响应基于贡献者团队的合理能力范围内处理。
