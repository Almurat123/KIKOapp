KiKo へようこそ！このガイドは、現在実装済みで直接利用できるクイックスタートフローを説明します。

<Steps>
  <Step title="1) サインイン（KiKo ウォレットを作成）">
    KiKo は **Privy** で認証します。対応方式：

    - **Google サインイン**
    - **Farcaster サインイン**
    - **Passkey**（Face ID / Touch ID / Windows Hello など）

    サインイン後、システムが自動で **Embedded Wallet** を作成。シードフレーズを覚える必要はありません。
  </Step>

  <Step title="2) 資金を入れる（Base から始める）">
    最初の取引を完了するには、KiKo ウォレットに資金を入れてください。

    - **Base（推奨）**：Gas が安く、初心者向け
    - **Ethereum**：Gas が高くなる場合あり
    - **Solana**：取引には **SOL** で手数料が必要（少なくとも **0.005 SOL** を保持）

    <Tip>
      やり方がわからない？「どのチェーンに残高がある？入金アドレスを教えて」と聞いてみてください。
    </Tip>
  </Step>

  <Step title="3) クエリを実行（準備完了を確認）">
    チャットで試してみてください：

    - 「ウォレット残高を見せて」
    - 「ETH の価格は？」
    - 「Base で取引量トップ 5 のトークンは？」
  </Step>

  <Step title="4) 最初の少額 Swap（少額から始める）">
    取引意図を直接入力、例：

    - 「20 USDC で ETH を買う」
    - 「Base で 50 USDC で DEGEN を買う」

    システムが取引カードを表示します（価格、スリッページ、価格影響、リスク通知）。設定と実行モードに応じて、手動確認が必要な場合と、Fast Swap モードで直接実行される場合があります。
  </Step>

  <Step title="5) 不慣れなトークンは取引前にスキャン">
    取引前にアドレスを送信：

    - 「このトークンは安全？0x...」
    - 「買う前にこのトークンのリスクをスキャンして：0x...」
  </Step>
</Steps>

<Warning>
  KiKo は投資アドバイスを提供しません。暗号資産は変動が大きいため、失っても許容できる金額のみ投資してください。
</Warning>
