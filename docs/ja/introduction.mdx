## KiKo とは？

**KiKo** は **大規模言語モデル（DeepSeek と xAI Grok）** と **オンチェーン実行エンジン** を深く統合したインテリジェントターミナルです。複雑な Web3 操作を自然言語で実行できます。

KiKo には取引のあらゆる側面をカバーするカスタムツールが組み込まれており、AI がこれらを協調させ、情報収集から取引実行までのフルフローを支援します。

<AccordionGroup>
  <Accordion title="主な機能">

### 取引実行

スマート取引実行、自動ルーティング最適化、マルチチェーン対応。自然言語でニーズを伝えるだけで、システムが最適なパスを見つけて取引を実行します。

[詳細 →](/ja/user-guides/swap-trading)

### リスクスキャン

包括的なセキュリティスキャンで潜在リスクを自動検出し、資金を保護。取引前に契約リスクを自動チェックし、詳細な評価レポートを提供します。

[詳細 →](/ja/user-guides/risk-and-security)

### 市場データ

リアルタイム市場データ、履歴トレンド分析、人気資産追跡。最新価格、取引量、流動性などの主要指標を取得できます。

### ソーシャルインテリジェンス

Farcaster、X（Twitter）などのプラットフォームのトレンド追跡、ホットトピック発見、通知機能を統合。

### 予測市場

Polymarket などの予測市場から集団的知恵を取得し、市場の将来イベントへの期待を把握。

### ウォレット分析

オンチェーン分析、損益追跡、行動監視で資産状況を把握。

### 自動化ツール

スマートコピートレード、価格アラート、行動監視などの自動化戦略。

[詳細 →](/ja/user-guides/copy-trading)

### リサーチツール

Web 検索でほぼあらゆる情報をクエリし、市場情報とリサーチ資料を取得。
